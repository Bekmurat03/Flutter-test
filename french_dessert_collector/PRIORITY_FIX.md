# 🔧 Исправление: Приоритеты отрисовки компонентов

## Проблема
Фон (синее небо) рисовался поверх всех элементов игры.

## Причина
У компонента `Background` не был установлен приоритет, и он добавлялся через `camera.backdrop.add()`, что приводило к неправильному порядку отрисовки.

## Решение

### 1. Добавлен приоритет для Background
```dart
class Background extends Component {
  @override
  Future<void> onLoad() async {
    await super.onLoad();
    
    // Самый низкий приоритет (рисуется первым, под всем)
    priority = -100;
  }
  
  @override
  void render(Canvas canvas) {
    // ... код отрисовки
  }
}
```

### 2. Изменен способ добавления фона
**Было:**
```dart
camera.backdrop.add(Background());
```

**Стало:**
```dart
await add(Background());
```

### 3. Добавлен приоритет для ParticleEffect
```dart
@override
Future<void> onLoad() async {
  await super.onLoad();
  
  // Приоритет выше предметов (чтобы эффект был виден)
  priority = 10;
  
  // ...
}
```

## Иерархия приоритетов (порядок отрисовки)

```
-100: Background (фон)          ← Рисуется первым (самый нижний слой)
  -1: GroundLine (линия земли)  ← Над фоном
   0: Player (игрок)            ← По умолчанию
   0: FallingItem (предметы)    ← По умолчанию
  10: ParticleEffect (эффекты)  ← Над предметами
1000: GameUI (интерфейс)        ← Рисуется последним (самый верхний слой)
```

## Как работает priority в Flame

- **Меньшее число** = рисуется раньше (ниже)
- **Большее число** = рисуется позже (выше)
- **По умолчанию** = 0
- Компоненты с одинаковым приоритетом рисуются в порядке добавления

## Результат

✅ Фон теперь рисуется под всеми элементами
✅ Игрок и предметы видны поверх фона
✅ UI отображается поверх всего
✅ Эффекты частиц видны над предметами

## Файлы изменены

- `lib/game/game_main.dart` - Background класс и onLoad()
- `lib/game/particle_effect.dart` - добавлен priority = 10
