# ✅ ЭТАП 5 ЗАВЕРШЕН: Падающие предметы и система спавна

## Что сделано:

### 1. Создан компонент FallingItem (падающий предмет)
**Файл:** `lib/game/falling_item.dart`

**Что это:**
- Компонент падающего предмета (десерт или кость)
- Падает сверху вниз с определенной скоростью
- Может быть пойман игроком или упасть мимо

**Свойства:**
- `itemType` - тип предмета (ItemType enum)
- `fallSpeed` - скорость падения в пикселях/секунду
- `isCaught` - флаг, был ли предмет пойман
- Размер: 50x50 пикселей (из GameConstants.itemSize)
- Эмодзи: зависит от типа (🥖, 🍰, 🧁, 🦴, 🐟)

**Методы:**

- `onLoad()` - инициализация при создании
  - Устанавливает случайную позицию X (в пределах экрана)
  - Начальная позиция Y = -size.y (чуть выше экрана)
  - Создает TextComponent с эмодзи
  
- `update(dt)` - обновление каждый кадр
  - Двигает предмет вниз: position.y += fallSpeed * dt
  - Проверяет, упал ли предмет за нижнюю границу
  - Если упал → вызывает _handleMissed()
  
- `_handleMissed()` - предмет упал мимо
  - Если это был хороший предмет (десерт) → game.loseHP()
  - Удаляет предмет: removeFromParent()
  
- `catchItem()` - предмет пойман игроком
  - Помечает isCaught = true
  - Добавляет/отнимает очки: game.addScore(itemType.score)
  - Если рыбная кость → game.loseHP()
  - Если пирожное → game.addTime(3 секунды)
  - Удаляет предмет
  
- `checkCollisionWithPlayer()` - проверка коллизии
  - Вычисляет расстояние между центрами (игрок и предмет)
  - Использует формулу: distance = sqrt(dx² + dy²)
  - Если distance < collisionRadius → есть коллизия
  - collisionRadius = (размер игрока + размер предмета) / 2 * 0.8

**Логика упущенного предмета:**
```
Предмет падает вниз
    ↓
position.y > высота экрана?
    ↓ Да
Это хороший предмет (десерт)?
    ↓ Да
game.loseHP() - теряем жизнь
    ↓
removeFromParent() - удаляем предмет
```

### 2. Создана система ItemSpawner (спавнер предметов)
**Файл:** `lib/game/item_spawner.dart`

**Что это:**
- Система автоматического создания падающих предметов
- Создает предметы через определенные интервалы
- Управляет частотой и типами предметов

**Свойства:**
- `_spawnTimer` - таймер до следующего спавна
- `_spawnInterval` - интервал спавна (1.5 секунды из констант)
- `_random` - генератор случайных чисел

**Методы:**

- `update(dt)` - обновление каждый кадр
  - Если пауза → не спавним
  - Увеличивает таймер: _spawnTimer += dt
  - Если _spawnTimer >= _spawnInterval → _spawnItem()
  - Сбрасывает таймер после спавна
  
- `_spawnItem()` - создает новый предмет
  - Выбирает случайный тип: _getRandomItemType()
  - Вычисляет скорость: _calculateFallSpeed()
  - Создает FallingItem
  - Добавляет в игру: game.add(item)
  
- `_getRandomItemType()` - выбор типа предмета
  - Использует вероятности:
    - 40% - Багет 🥖 (базовый десерт, +10 очков)
    - 25% - Макарон 🍰 (средний десерт, +20 очков)
    - 15% - Пирожное 🧁 (лучший десерт, +30 очков + 3 сек)
    - 15% - Кость 🦴 (плохой предмет, -10 очков)
    - 5% - Рыбная кость 🐟 (очень плохой, -20 очков и -1 HP)
  
- `_calculateFallSpeed()` - вычисление скорости
  - Базовая скорость: 200 пикселей/сек
  - Увеличение каждые 100 очков: +50 пикселей/сек
  - Максимальная скорость: 500 пикселей/сек
  - Формула: speed = 200 + (score / 100) * 50
  
- `clearAllItems()` - очистка всех предметов
  - Получает все FallingItem из игры
  - Удаляет каждый предмет
  - Вызывается при restart()

**Вероятности предметов:**
```
Случайное число 0-99:
  0-39  (40%) → Багет 🥖
  40-64 (25%) → Макарон 🍰
  65-79 (15%) → Пирожное 🧁
  80-94 (15%) → Кость 🦴
  95-99 (5%)  → Рыбная кость 🐟
```

## Как работает игровой цикл:

### Спавн предметов:
```
Каждый кадр (60 раз в секунду):
  ItemSpawner.update(dt)
    ↓
  _spawnTimer += dt
    ↓
  _spawnTimer >= 1.5 секунды?
    ↓ Да
  _spawnItem()
    ↓
  Выбор случайного типа (40% багет, 25% макарон...)
    ↓
  Вычисление скорости (зависит от счета)
    ↓
  Создание FallingItem
    ↓
  Добавление в игру
    ↓
  Сброс таймера
```

### Падение предмета:
```
Каждый кадр:
  FallingItem.update(dt)
    ↓
  position.y += fallSpeed * dt
    ↓
  Предмет двигается вниз
    ↓
  position.y > высота экрана?
    ↓ Да
  Это десерт? → loseHP()
    ↓
  removeFromParent()
```

### Проверка коллизий:
```
Каждый кадр:
  GameMain.update(dt)
    ↓
  _checkCollisions()
    ↓
  Для каждого FallingItem:
    ↓
  item.checkCollisionWithPlayer()?
    ↓ Да
  item.catchItem()
    ↓
  Добавить очки
  Проверить бонусы (время, HP)
    ↓
  removeFromParent()
```

### Увеличение скорости:
```
Счет: 0-99   → Скорость: 200 пикс/сек
Счет: 100-199 → Скорость: 250 пикс/сек
Счет: 200-299 → Скорость: 300 пикс/сек
Счет: 300-399 → Скорость: 350 пикс/сек
Счет: 400-499 → Скорость: 400 пикс/сек
Счет: 500+    → Скорость: 450 пикс/сек
Максимум:     → Скорость: 500 пикс/сек
```
