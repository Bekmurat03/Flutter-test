# ✅ ЭТАП 3 ЗАВЕРШЕН: Подключение Flame и создание игрового класса

## Что сделано:

### 1. Создан GameMain (главный игровой класс)
**Файл:** `lib/game/game_main.dart`

**Что это:**
- Основной класс игры, наследуется от FlameGame
- Управляет всей игровой логикой: счет, HP, таймер
- Содержит методы для обновления игры каждый кадр

**Игровые переменные:**
- `score` - текущий счет игрока (начинается с 0)
- `hp` - количество жизней (начинается с 3)
- `timeLeft` - оставшееся время в секундах (начинается с 30)
- `isPaused` - флаг паузы

**Методы:**
- `onLoad()` - вызывается один раз при загрузке игры
  - Добавляет фон (градиент)
  - Добавляет UI компонент
  
- `update(dt)` - вызывается каждый кадр (60 раз в секунду)
  - Уменьшает таймер
  - Проверяет условия окончания игры
  - dt = время с предыдущего кадра в секундах
  
- `_checkGameOver()` - проверяет условия окончания
  - Если время <= 0 → игра заканчивается ("Time's up!")
  - Если HP <= 0 → игра заканчивается ("No HP left!")
  
- `_endGame(reason)` - завершает игру
  - Ставит паузу
  - Вызывает callback onGameOver с результатами
  
- `addScore(points)` - добавляет очки к счету
- `addTime(seconds)` - добавляет время к таймеру
- `loseHP()` - отнимает 1 HP
- `togglePause()` - переключает паузу
- `resume()` - возобновляет игру
- `restart()` - перезапускает игру (сброс всех значений)

**Callback onGameOver:**
- Передается при создании игры
- Вызывается когда игра заканчивается
- Передает финальный счет и причину окончания

### 2. Создан GameUI (компонент UI)
**Файл:** `lib/game/game_ui.dart`

**Что делает:**
- Рисует игровую информацию поверх игрового поля
- Обновляется каждый кадр автоматически

**Что отображает:**
- **Score** (по центру сверху) - текущий счет, желтым цветом
- **HP** (слева сверху) - количество жизней с иконкой ❤️
- **Timer** (справа сверху) - оставшееся время с иконкой ⏱️

**Как работает:**
- Наследуется от PositionComponent
- Использует HasGameReference для доступа к GameMain
- Метод render() рисует текст на canvas каждый кадр
- Высокий приоритет (1000) чтобы рисоваться поверх всего

### 3. Создан PauseOverlay (overlay паузы)
**Файл:** `lib/game/pause_overlay.dart`

**Что это:**
- Flutter виджет, который показывается поверх игры
- Полупрозрачный черный фон с белой карточкой

**Кнопки:**
- **Continue** (зеленая) - возобновляет игру
  - Вызывает game.resume()
  - Скрывает overlay паузы
  
- **Restart** (оранжевая) - перезапускает игру
  - Вызывает game.restart()
  - Сбрасывает счет, HP, время
  - Скрывает overlay паузы
  
- **Quit** (красная) - выход из игры
  - Возвращается на главный экран
  - Удаляет все промежуточные экраны

**Как работает:**
- Получает ссылку на game при создании
- Использует game.overlays для управления видимостью
- Вспомогательный метод _buildButton() для единообразия кнопок

### 4. Создан Background (компонент фона)

**Файл:** `lib/screens/game_screen.dart`

**Что изменилось:**
- Теперь StatefulWidget (был StatelessWidget)

## Как это все работает вместе:

### Запуск игры:
1. Пользователь вводит имя на NameScreen
2. Переходит на GameScreen
3. GameScreen создает GameMain с именем игрока
4. GameMain.onLoad() загружает фон и UI
5. Игра начинается, update() вызывается 60 раз в секунду

### Игровой цикл:
```
update(dt) каждый кадр:
  ├─ Если пауза → ничего не делаем
  ├─ Уменьшаем таймер (timeLeft -= dt)
  └─ Проверяем окончание игры
      ├─ Если время <= 0 → _endGame("Time's up!")
      └─ Если HP <= 0 → _endGame("No HP left!")
```

### Пауза:
1. Игрок нажимает кнопку паузы
2. Вызывается _showPauseOverlay()
3. game.togglePause() → isPaused = true
4. game.overlays.add('pause') → показывается PauseOverlay
5. update() перестает обновлять логику (проверка isPaused)

### Окончание игры:
1. Условие выполнено (время или HP)
2. _endGame(reason) → isPaused = true
3. onGameOver(score, reason) → callback
4. _handleGameOver() в GameScreen
5. Переход на GameOverScreen с результатами
