# ✅ ЭТАП 2 ЗАВЕРШЕН: Создание экранов и навигации

## Что сделано:

### 1. Создан NameScreen (экран ввода имени)
**Файл:** `lib/screens/name_screen.dart`

**Что делает:**
- Показывает поле для ввода имени игрока
- Валидация: имя не может быть пустым и должно быть минимум 2 символа
- Кнопка "Start Game" - переход к игре
- Кнопка "Back" - возврат на главный экран

**Как работает:**
- Использует TextFormField с контроллером для управления вводом
- Валидация через validator (проверяет имя перед переходом)
- При нажатии "Start Game" передает имя на GameScreen
- Можно нажать Enter на клавиатуре вместо кнопки

### 2. Создан GameScreen (экран игры)
**Файл:** `lib/screens/game_screen.dart`

**Что делает:**
- Принимает имя игрока с предыдущего экрана
- Пока это заглушка (черный экран с текстом)
- На следующем этапе здесь будет Flame GameWidget

**Параметры:**
- `playerName` - имя игрока (обязательный параметр)

### 3. Создан GameOverScreen (экран окончания игры)
**Файл:** `lib/screens/game_over_screen.dart`

**Что делает:**
- Показывает результаты игры после окончания
- Отображает: имя игрока, финальный счет, причину окончания
- Красивая карточка с результатами на темном фоне

**Параметры:**
- `playerName` - имя игрока
- `finalScore` - финальный счет (очки)
- `reason` - причина окончания ("Time's up!" или "No HP left!")

**Кнопки:**
- "View Ranking" - переход к таблице лидеров
- "Play Again" - возврат на главный экран для новой игры

### 4. Создан RankingScreen (экран рейтинга)
**Файл:** `lib/screens/ranking_screen.dart`

**Что делает:**
- Показывает таблицу лидеров (топ-10 игроков)
- Загружает данные из локального хранилища
- Медали для топ-3: 🥇 🥈 🥉
- Золотой фон для первого места

**Как работает:**
- При открытии экрана вызывается `_loadRankings()`
- Показывает индикатор загрузки пока данные загружаются
- Если рейтинг пустой, показывает сообщение "No scores yet"
- Список результатов с именем и очками каждого игрока

### 5. Создана модель PlayerScore
**Файл:** `lib/models/player_score.dart`

**Что содержит:**
- `playerName` - имя игрока
- `score` - количество очков
- `timestamp` - дата и время игры

**Методы:**
- `fromJson()` - создает объект из JSON (для загрузки)
- `toJson()` - преобразует объект в JSON (для сохранения)

### 6. Создан RankingService (сервис рейтинга)
**Файл:** `lib/services/ranking_service.dart`

**Что делает:**
- Сохраняет результаты игроков в локальное хранилище
- Загружает рейтинг из хранилища
- Хранит только топ-10 лучших результатов
- Автоматически сортирует по очкам

**Методы:**
- `saveScore(playerName, score)` - сохраняет новый результат
- `getRankings()` - загружает список результатов
- `clearRankings()` - очищает рейтинг (для тестирования)

**Как работает сохранение:**
1. Загружаем текущий рейтинг
2. Добавляем новый результат
3. Сортируем по убыванию очков
4. Оставляем только топ-10
5. Сохраняем в shared_preferences в формате JSON

### 7. Обновлен HomeScreen
**Файл:** `lib/screens/home_screen.dart`

**Что добавлено:**
- Кнопка "Game Start" теперь работает - переход на NameScreen
- Добавлена кнопка "Ranking" - переход к таблице лидеров
- Импорты для навигации

## Навигация в приложении:

```
HomeScreen (главное меню)
    ↓ "Game Start"
NameScreen (ввод имени)
    ↓ "Start Game"
GameScreen (игра) ← пока заглушка
    ↓ (игра заканчивается)
GameOverScreen (результаты)
    ↓ "View Ranking"
RankingScreen (таблица лидеров)
    ↓ "Back" или "Play Again"
HomeScreen (возврат в меню)
```

## Что можно протестировать:

```bash
cd french_dessert_collector
flutter run
```

**Проверь:**
1. Главный экран - две кнопки: "Game Start" и "Ranking"
2. Нажми "Ranking" - увидишь пустой рейтинг
3. Нажми "Game Start" - откроется экран ввода имени
4. Введи имя (минимум 2 символа) и нажми "Start Game"
5. Откроется GameScreen (пока заглушка с черным фоном)
6. Можешь вернуться назад кнопкой "Back to Home"
