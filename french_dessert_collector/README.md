# French Dessert Collector 🥐

Простая 2D мобильная игра на Flutter + Flame

## 📖 Описание игры

Ловите французские десерты и избегайте костей! Управляйте поваром внизу экрана, собирайте очки и следите за здоровьем. У вас есть 30 секунд и 3 жизни чтобы набрать максимальный счет!

## 🎮 Как играть

### Управление
- Перетаскивайте пальцем (или мышкой) влево-вправо для движения повара

### Предметы

**Хорошие (ловите их!):**
- 🥖 Багет: +10 очков
- 🍰 Макарон: +20 очков  
- 🧁 Пирожное: +30 очков + 30 секунд времени

**Плохие (избегайте!):**
- 🦴 Кость: -10 очков
- 🐟 Рыбная кость: -20 очков и -1 HP

### Правила
- Начальные жизни: 3 HP ❤️
- Время игры: 30 секунд ⏱️
- Пропустили десерт → -1 HP
- Поймали рыбную кость → -1 HP
- **Каждые 50 очков → +1 HP бонус** 💚
- Скорость увеличивается каждые 100 очков
- Игра заканчивается при HP = 0 или времени = 0

## 🔧 Настройка игры

Все параметры игры находятся в `lib/models/game_constants.dart`:

```dart
// Игровые параметры
initialHP = 3              // Начальные жизни
gameDuration = 30          // Длительность в секундах

// Очки за предметы
baguetteScore = 10
macaronScore = 20
puffScore = 30
boneScore = -10
fishboneScore = -20

// Скорость
initialFallSpeed = 200.0   // Начальная скорость
speedIncreaseInterval = 100 // Через сколько очков ускорение
speedIncreaseAmount = 50.0  // На сколько ускоряется
maxFallSpeed = 500.0       // Максимальная скорость

// Размеры
playerSize = 60.0
itemSize = 50.0

// Спавн
itemSpawnInterval = 1.5    // Интервал появления предметов
```
