/// Проверяет и добавляет HP бонус каждые 50 очков
void _checkHPBonus(int oldScore, int newScore) {
  final oldMilestone = oldScore ~/ GameConstants.hpBonusInterval;
  final newMilestone = newScore ~/ GameConstants.hpBonusInterval;
  
  if (newMilestone > oldMilestone) {
    final hpToAdd = newMilestone - oldMilestone;
    hp += hpToAdd;
    debugPrint('HP Bonus! +$hpToAdd HP (reached ${newMilestone * 50} points)');
  }
}

## Полные правила игры

### Предметы:
- 🥖 **Baguette**: +10 очков
- 🍰 **Macaron**: +20 очков
- 🧁 **Puff**: +30 очков + 30 секунд времени
- 🦴 **Bone**: -10 очков
- 🐟 **Fishbone**: -20 очков и -1 HP

### Система HP:
- Начальные жизни: **3 HP**
- Пропустил десерт: **-1 HP**
- Поймал рыбную кость: **-1 HP**
- **Каждые 50 очков: +1 HP** (новое!)

### Прогрессия:
- Скорость увеличивается каждые **100 очков**
- Начальная скорость: 200 пикс/сек
- Увеличение: +50 пикс/сек
- Максимум: 500 пикс/сек

### Условия окончания:
- HP достигает 0
- Время достигает 0 (30 секунд)

## Баланс игры

### Стратегия для игрока:
1. **Приоритет на пирожные** 🧁 - дают время и много очков
2. **Не пропускать десерты** - каждый пропуск = -1 HP
3. **Избегать костей** - особенно рыбных
4. **Набирать 50 очков** для восстановления HP
5. **Использовать бонусное время** от пирожных

### Сложность:
- **0-100 очков**: Легко (медленная скорость)
- **100-200 очков**: Средне (скорость +50)
- **200-300 очков**: Сложно (скорость +100)
- **300+ очков**: Очень сложно (скорость +150+)

### Время:
- Базовое время: 30 секунд
- Каждое пирожное: +30 секунд
- Максимально возможное время: неограничено (если ловить пирожные)
