# ✅ ЭТАП 1 ЗАВЕРШЕН: Создание проекта и подключение Flame

## Что сделано:

### 1. Создан Flutter проект
- Проект называется `french_dessert_collector`
- Используется Flutter 3.38.7 и Dart 3.10.7

### 2. Добавлены зависимости
В `pubspec.yaml` добавлены:
- `flame: ^1.18.0` - игровой движок для создания 2D игры
- `shared_preferences: ^2.2.2` - для сохранения рейтинга игроков

### 3. Создана структура проекта
```
lib/
├── main.dart                      # Точка входа, настройка ориентации
├── screens/                       # Папка для экранов
│   └── home_screen.dart          # Главное меню с кнопкой "Game Start"
├── game/                         # Папка для игровой логики (пока пустая)
├── models/                       # Папка для моделей данных
│   ├── game_constants.dart       # Все константы игры
│   └── item_type.dart           # Типы предметов (багет, макарон и т.д.)
└── services/                     # Папка для сервисов (пока пустая)
```

### 4. Созданные файлы:

#### main.dart
- Настроена портретная ориентация (игра не поворачивается)
- Создан корневой виджет MyApp
- Установлена тема приложения (синий цвет)
- Начальный экран - HomeScreen

#### home_screen.dart
- Красивый градиентный фон (голубой → розовый)
- Иконка десерта 🥐
- Название игры "French Dessert Collector"
- Кнопка "Game Start" (пока без навигации)

#### game_constants.dart
- HP = 3 жизни
- Таймер = 30 секунд
- Очки: багет +10, макарон +20, пирожное +30
- Штрафы: кость -10, рыбная кость -20 и -1 HP
- Настройки скорости падения предметов
- Размеры игрока и предметов

#### item_type.dart
- Enum с 5 типами предметов
- Каждый тип имеет эмодзи для отображения
- Методы для получения очков, проверки типа предмета
- Логика бонусов (пирожное дает +3 секунды)

## Как это работает:

1. **main.dart** запускается первым
   - Блокирует поворот экрана
   - Создает MaterialApp
   - Показывает HomeScreen

2. **HomeScreen** - это главное меню
   - Показывает название игры
   - Кнопка "Game Start" (на следующем этапе добавим навигацию)

3. **Модели данных** готовы
   - Все константы в одном месте (легко балансировать игру)
   - Типы предметов с их свойствами

## Что можно протестировать:

```bash
cd french_dessert_collector
flutter run
```

Вы увидите:
- Красивый главный экран
- Иконку десерта
- Название игры
- Кнопку "Game Start" (пока ничего не делает)
